# projekt quiz i bmi w vue-3

cd moj-projekt


## instalacja

```sh
npm install
```

### uruchomienie

```sh
npm run dev
```

### Type-Check

```sh
npm run build
```


### testy 

npm run test           # tryb watch – idealny w trakcie pisania
npm run test:run       # jednorazowo (CI)
npm run test:coverage  # z raportem pokrycia
vitest --ui            #otwiera dashboard w przeglądarce
